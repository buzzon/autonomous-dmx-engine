## 9. Технические проблемы и решения

### Проблема с fft.js:
**Проблема:** Библиотека `fft.js` вызывает ошибку "Cannot read properties of undefined (reading '0')" в Node.js v23.4.0
**Решение:** Использован mock для unit тестов. Для production требуется:
1. Использовать альтернативную библиотеку (например, `dsp.js`)
2. Или понизить версию Node.js
3. Или исправить библиотеку

### Проблема с node-web-audio-api:
**Проблема:** Библиотека `node-web-audio-api` требует специфичного окружения
**Решение:** Использован `node-microphone` для захвата аудио с микрофона
